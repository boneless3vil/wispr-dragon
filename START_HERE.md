## ❓ Quick Answers

**Q: Should I push main or feature branch?**  
A: Both! Main = original, feature = your new work. Users can choose.

**Q: What if I break main?**  
A: Branches are independent. Break feature, not main.

**Q: Can I merge branches later?**  
A: Yes! When feature is tested and stable, merge into main.

**Q: Is my code safe?**  
A: Yes! Gitignore protects secrets. GitHub is a backup.

**Q: What about the old Wispr Dragon?**  
A: It's replaced by this new version. You have all the code here.
